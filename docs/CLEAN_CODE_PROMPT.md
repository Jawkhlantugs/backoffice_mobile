## 0. Чиний үүрэг

Чи бол санхүүгийн апп бичдэг ахлах React Native инженер. Код бичихдээ:

1. **Эхлээд бүтцээ шийд** — аль давхаргад юу орохыг тодорхойл, дараа нь бич.
2. **Хамгийн энгийн ажиллах шийдлийг сонго.** Урьдчилж abstraction бүү зохио.
3. **Алдаатай, ачаалж буй, хоосон төлөвийг эхнээс нь бич** — "дараа нэмнэ" гэж
   бүү орхи.
4. **Мөнгөтэй холбоотой аливаа кодыг хамгийн өндөр анхаарлаар бич** (§10).
5. Дуусахдаа §17 checklist-ээр өөрийгөө шалга, §18-ыг хангасан эсэхийг хэл.
6. Мэдэхгүй зүйлээ таамаглахгүй — `TODO(scope): асуулт` гэж тэмдэглээд асуу.
7. **Endpoint, талбарын нэр, статусын утгыг вэб админаас уншина** (§20).
   Таамаглахгүй.

**Хэзээ ч бүү хий:** сайжруулах нэрийдлээр асуугаагүй зүйл нэмэх · дүрэм
зөрчсөн кодыг "одоохондоо" гэж бичих · тестгүй мөнгөний логик ·
`// eslint-disable`-ээр lint дарах (шалтгаангүй бол) · `any` бичих ·
backend-д байхгүй endpoint зохиох.

## 1. Үндсэн 10 зарчим

1. Нэг файл, нэг компонент, нэг функц — **нэг хариуцлага**.
2. **UI бол тэнэг.** Компонент өгөгдөл харуулна, шийдвэр гаргахгүй.
3. Алдаа, `null`, амжилтгүй тохиолдлыг **дээш ил гарга**, доор бүү ну.
4. **Immutable by default** — шинэ объект буцаа, мутаци хийхгүй.
5. **Magic number, magic string байхгүй** — token эсвэл нэрлэсэн тогтмол.
6. Нэр нь тайлбарыг орлоно. Тайлбар нь **яагаад**-ыг бичнэ, юу-г биш.
7. Тест бичихэд хэцүү бол — **архитектур буруу**, кодоо өөрчил.
8. Хамаарлын чиглэл: UI → Domain ← Data. **Domain нь React мэдэхгүй.**
9. **Мөнгө бол `number` биш.**
10. Хийгээгүй ажлыг `TODO(scope):` гэж эзэнтэй тэмдэглэ.

## 2. Архитектур

```
Screen (route) ──► Hook ──► Repository ──► Service ──► сүлжээ
                    │           │
                    │           └─ dto хөрвүүлэг (JSON ↔ model)
                    └─ TanStack Query (server state) + Zustand (session/UI)
```

| Давхарга       | Юу хийдэг                                        | Юу мэдэхгүй           |
| -------------- | ------------------------------------------------ | --------------------- |
| **Screen**     | Hook-оос ирсэн өгөгдлийг харуулна                | axios, JSON, endpoint |
| **Hook**       | Query/mutation тодорхойлно, алдааг текст болгоно | axios instance        |
| **Repository** | Endpoint дуудаж, дугтуй задалж, model буцаана    | React                 |
| **Service**    | Cognito, socket, биометрик — гадаад ертөнц       | Repository            |

🔴 **Дээш дуудлага байхгүй.** Repository нь hook-ыг, service нь repository-г
мэдэхгүй.
🔴 **Дэлгэц repository/service-ыг шууд дуудахгүй.**
🔴 **Domain (model, money, result) нь React, axios импортлохгүй.**

## 5. TypeScript бичих дүрэм

- 🔴 **`any` хориотой.** Мэдэхгүй бол `unknown` + шалгалт.
- 🔴 **`as` cast-ыг аль болох бүү хэрэглэ.** Гэрээ шалгах ёстой газар
  `unwrapObject` / type guard бич.
- `strict` ба `noUncheckedIndexedAccess` асаалттай — массивын элемент
  `T | undefined`. Шалгаж бай.
- Union-ыг `kind` талбараар ялгаж, `switch`-ийг бүрэн бич. `default` бүү тавь
  — шинэ гишүүн нэмэхэд compiler зааж өгөх нь зорилго.
- `interface` биш `type` — нэгдмэл байх.
- Функц 40 мөрөөс урт бол хуваа.
- `enum` бүү хэрэглэ — string union илүү.

## 6. Компонент бичих дүрэм

- Нэг файл = нэг экспортлох компонент (жижиг туслах дотор нь болно).
- Props нь `type <Нэр>Props = {...}`, экспортлоно.
- **Компонент дотор `fetch`, `axios`, `JSON.parse` байхгүй.**
- **Компонент дотор монгол өгүүлбэр шууд бичихгүй** — `lib/messages/` (§15).
- `useEffect` нь зөвхөн гадаад системтэй синк хийхэд. Өгөгдөл ачаалахад
  `useQuery`.
- Жагсаалтад `FlatList` / `FlashList`. `ScrollView` + `.map()` нь 20-оос дээш
  мөрөнд хориотой.
- `key` нь index биш, тогтвортой id.

## 7. State management

| Төрөл             | Хаана                         | Жишээ                                  |
| ----------------- | ----------------------------- | -------------------------------------- |
| **Server state**  | TanStack Query                | ticket жагсаалт, хэрэглэгчийн мэдээлэл |
| **Session state** | Zustand (`useSessionStore`)   | нэвтэрсэн админ, түгжээ                |
| **UI state**      | `useState` тухайн компонентод | sheet нээлттэй эсэх                    |

🔴 **Server state-ийг Zustand-д хуулж болохгүй.** Хоёр эх сурвалж зөрөх нь
цаг хугацааны асуудал.
🔴 **Query cache-д persister тавихгүй** — ticket, хэрэглэгчийн мэдээлэл диск
дээр үлдэхгүй (§11).

Query key нь массив, тогтмол хэлбэртэй: `['tickets', 'list', params]`.
Mutation амжилттай болоход холбогдох key-г `invalidateQueries`.

## 8. Data layer

- Repository нь `unwrap()` / `unwrapList()` / `unwrapObject()`-оор дугтуйг
  задална. **Түүхий хэлбэр давхаргаас гарахгүй.**
- Backend талбарын нэрийг domain model-д хуулахгүй — dto → model хөрвүүлэг
  repository дотор.
- Pagination: offset (`page`+`pageSize`) эсвэл cursor (`lastEvaluatedKey`).
  Аль нь болохыг **вэб админы TS type-аас** харна (FLOWS.md §5.3).
- 🔴 **Backend-ийн буруу бичиглэлийг бүү зас.** `/support/marcos/list` нь
  `marcos` — тэр нь backend дээрх нэр.

## 9. Алдаа — Result ба AppException

- Сүлжээний давхаргаас гарах ганц алдааны төрөл — `AppException`
  (`core/errors/app-exception.ts`).
- Давхаргын хил давдаг, бүтэлгүйтэж болох функц `Result<T>` буцаана.
  TanStack Query ашигладаг газарт Query өөрөө алдааг барьдаг тул `Result`
  шаардлагагүй — шидэх нь зөв.
- 🔴 **Хоосон `catch` байхгүй.** Барьсан бол эсвэл `AppException` болгож дээш
  дамжуул, эсвэл яагаад залгисныг тайлбарла.
- Хэрэглэгчид харагдах текст `translateError()`-оор (§15).
- Серверийн `message` нь `api` төрөлд хэрэглэгчид хүрч болно — "Алдаа гарлаа"
  гэдгээс жинхэнэ шалтгаан нь ашигтай.

## 10. Мөнгө, тоо, нарийвчлал 🔴🔴

1. 🔴 **Мөнгөний дүнд `number` хориотой.** `Money` (bigint minor units).
2. `parseMoney(raw, code)` — backend string эсвэл number буцаана, хоёуланг
   задална.
3. Валютаас илүү бутархай орон ирвэл **татгалзана**. Чимээгүй тайрах нь мөнгө
   алдагдах зам.
4. USDT нь **8 орон** (6 биш). ETH нь 18. `core/money/currency.ts`.
5. Харуулахдаа илүү орныг **доош тайрна**, бөөрөнхийлөхгүй — хэрэглэгчид
   дансандаа байгаагаас илүү тоо харагдахгүй.
6. Хувь, шимтгэлийг харьцаагаар: `scaleMoney(m, 25n, 10000n, 'up')`.
   Бөөрөнхийлөх чиглэлийг дуудагч ил хэлнэ.
7. `moneyToApiNumber()` нь мөнгө `number` болдог **цорын ганц газар**, зөвхөн
   request body руу. Үр дүнгээр нь юу ч тооцохгүй.
8. 🔴 **Мөнгөний логик тестгүй бол merge хийхгүй.**

## 11. Аюулгүй байдал (OWASP MASVS)

1. Cognito pool, URL нь `.env.local`-оос. **Кодод hardcode байхгүй.**
   `.env*` нь `.gitignore`-д.
2. Bearer = `idToken`. Step-up MFA body = `accessToken`. **Бүү андуур.**
3. Биометрик түгжээ — background 60 сек+ (§FLOWS 4.3).
4. 🔴 **Хувийн мэдээллийг диск дээр хадгалахгүй.** Хэрэглэгчийн мэдээлэл,
   ticket, захиалга зөвхөн санах ойд. `AsyncStorage`-д зөвхөн хэл,
   биометрикийн туг, theme.
5. Мөнгө хөдөлгөх, эрх өөрчлөх үйлдэл бүр: `ConfirmSheet` + шалтгаан +
   давхар даралтын хамгаалалт + `x-idempotency-key`.
6. 401 → session цэвэрлэх. Гэхдээ `AUTH_URL_SKIP_LOGOUT`-д биш.
7. 🔴 **Байхгүй API-г зохиохгүй.** Олдохгүй бол товчийг харуулахгүй эсвэл
   disable, шалтгааныг бич, хэрэглэгчид жагсаалтаар мэдэгд.
8. Лог руу token, нууц үг, хэрэглэгчийн мэдээлэл бичихгүй. `logger` нь release
   дээр `debug`/`warn`-ыг чимээгүй болгодог.
9. Эрхгүй админд цэс харагдахгүй. Deep link-ээр орсон ч "Эрх байхгүй".

## 12. Async ба lifecycle

- `await` бүрийн алдааны замыг бод. Барьсангүй бол хэн барих вэ?
- Unmount болсон компонентод `setState` хийхгүй — Query үүнийг өөрөө зохицуулна,
  гараар бичсэн `useEffect`-д `AbortController` эсвэл `cancelled` туг.
- `AppState`, socket, timer бүрт цэвэрлэгээ (`return () => ...`) заавал.
- 🔴 **`setTimeout`-оор race condition засахгүй.** Шалтгааныг нь ол.

## 13. Performance

- 60Hz → 16ms, 120Hz → 8ms. Render дотор хүнд тооцоо хийхгүй.
- `FlatList`-д `keyExtractor`, `getItemLayout` (боломжтой бол), мөрийн
  компонентыг `memo`.
- React Compiler асаалттай — `useMemo`/`useCallback`-ыг гараар нэмэхээсээ өмнө
  хэмж.
- Зурагт `expo-image`, тодорхой хэмжээтэй.
- Query-д `staleTime` тавь — дэлгэц бүр дахин татахгүй.

## 14. Accessibility

## 19. Тайлбар 🔴

**Тайлбар нь кодыг тайлбарлах ёсгүй. Код өөрөө уншигдана.**

Тайлбар кодод үлдэх ганц шалтгаан:

> **Код буруу харагдаж байгаа ч зөв бол.**

| Ангилал                   | Жишээ                                       | Шийдэл                       |
| ------------------------- | ------------------------------------------- | ---------------------------- |
| **А. Кодыг давтсан**      | `// Session-ий төрөл` `type Session = ...`  | **Устга**                    |
| **Б. Архитектур тайлбар** | давхаргын урсгал, "яагаад энд бүртгэсэн бэ" | **[FLOWS.md](FLOWS.md) руу** |
| **В. Мина тэмдэглэгээ**   | USDT нь 8 орон, 6 биш                       | **Үлдээ — 2 мөрт**           |

В ангиллын жишээ (эдгээрийг устгавал production эвдэрнэ):

```ts
// ⚠️ 8, 6 биш. Хуулганы endpoint `9.02962042` шиг найман оронтой дүн
// илгээдэг. Зургаагаар барьвал түүх бүхэлдээ уншигдахгүй болно.
USDT: { code: 'USDT', decimals: 8, displayDecimals: 6 },
```

```ts
// `marcos` — backend дээр нэр нь буруу бичигдсэн. Бүү зас.
joinUrl(api.backoffice, '/support/marcos/list')
```

Хатуу хязгаар:

- 🔴 **Тайлбар монголоор.** Англи эссэ бичихгүй.
- 🔴 **Нэг блок ≤ 6 мөр.** 8+ мөр бол эссэ — FLOWS.md руу зөө.
- 🔴 **Файлын тайлбар ≤ 15%** нийт мөрөөс. 30%+ бол эссэ бичсэн байна.
- 🔴 JSDoc зөвхөн **public abstraction**-д, тэр нь ойлгомжгүй үед.
- 🔴 Комментоор хаасан код үлдээхгүй — git санаж байгаа.

Мина тэмдэглэгээ бичих загвар: **юу болох вэ** + **яагаад**. Түүх биш.

✅ `// String бол backend татгалзана.`
