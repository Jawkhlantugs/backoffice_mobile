⚠️ Макет дээрх доод табын нэрс дэлгэц бүрт зөрж гарсан. Кодод баримтлах
жинхэнэ таб: **Нүүр · Цэс · Ажил · Профайл** (`components/app-tab-bar.tsx`
-ийн `TAB_ITEMS`).

Макетаас **зөрсөн** зүйлс — кодыг баримтална:

| Макет дээр                      | Кодод                                            |
| ------------------------------- | ------------------------------------------------ |
| Таб: Ticket, Гүйлгээ            | Цэс, Ажил — Ticket/Гүйлгээ хараахан хийгдээгүй   |
| Цэс нь нүүрэн дээр урт жагсаалт | Цэс нь drawer (вэбийн sidebar) + тусдаа таб      |
| Дүрсгүй мөрүүд                  | `AppIcon` (`expo-symbols`) — модуль бүр өнгөтэй  |
| Цагаан дэвсгэр                  | Анхны theme харанхуй, дэвсгэр гурван давхаргатай |

⚠️ Дүрсний сан нэмээгүй: `expo-symbols` нь iOS дээр SF Symbols, Android дээр
Material Symbols зурдаг тул `@expo/vector-icons` шаардлагагүй болсон.
