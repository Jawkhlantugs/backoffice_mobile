## 1. Өнгө 🟩

Semantic токен — компонент нь `bg-card`, `text-muted-foreground` гэж
нэрээр нь хэрэглэнэ. Hex код компонент дотор **хэзээ ч** бичигдэхгүй.

| Token                            | Light     | Dark      | Вэбээс |
| -------------------------------- | --------- | --------- | ------ |
| `background`                     | `#ffffff` | `#020618` | 🟩     |
| `foreground`                     | `#020618` | `#f8fafc` | 🟩     |
| `card`                           | `#ffffff` | `#020919` | 🟩     |
| `elevated`                       | `#ffffff` | `#0f172b` | 🟩 (`popover`) |
| `popover`                        | `#ffffff` | `#0f172b` | 🟩     |
| `primary`                        | `#0f172b` | `#e2e8f0` | 🟩     |
| `primary-foreground`             | `#f8fafc` | `#0f172b` | 🟩     |
| `secondary` / `muted` / `accent` | `#f1f5f9` | `#1d293d` | 🟩     |
| `muted-foreground`               | `#62748e` | `#90a1b9` | 🟩     |
| `destructive`                    | `#e7000b` | `#ff6467` | 🟩     |
| `success`                        | `#12b76a` | `#32d583` | 🟨 нэмсэн |
| `warning`                        | `#f79009` | `#fdb022` | 🟨 нэмсэн |
| `border`                         | `#e2e8f0` | `#1b1f2f` | 🟩     |
| `border-strong`                  | `#cbd5e1` | `#334155` | 🟨 нэмсэн |
| `input`                          | `#e2e8f0` | `#282b3b` | 🟩     |
| `ring`                           | `#90a1b9` | `#6a7282` | 🟩     |

⚠️ Вэб дээр харанхуй `border` нь `oklch(1 0 0 / 10%)` — цагаан 10% тунгалаг.
RN-д тунгалаг хүрээ давхарлагдахад өөр өнгө өгдөг тул дэвсгэр дээр нь
нийлүүлж хатуу hex болгосон (`#1b1f2f`). `input` нь мөн адил 15%.

🔴 **Өнгө зөвхөн утга илэрхийлнэ — дүрсэнд хэзээ ч биш.** Вэб админы sidebar
шиг дүрс бүгд цагаан (`foreground`) эсвэл саарал (`muted-foreground`).
Статусын өнгө pill, текст, хүрээнд л. Модуль тус бүрийг өнгөөр
ялгахыг **оролдож үзээд хассан** — 28 модуль долоон өнгөөр будагдахад
жагсаалт шуугиантай болж, аль өнгө нь юу гэсэн үг болох нь ойлгомжгүй байв.

### 1.1 Гадаргуугийн давхарга 🟩

```
background  →  card  →  elevated (= popover)
дэвсгэр        карт     drawer · tab bar · bottom sheet
```

Харанхуй горимд `card` (#020919) нь дэвсгэрээс (#020618) бараг ялгарахгүй —
**вэб дээр ч яг ийм**. Картын хил нь өнгөөр биш **1px `border`-оор** гарна.
Drawer, tab bar зэрэг хөвөгч гадаргуу нь `elevated` (#0f172b) — вэбийн
`popover` токен.

### 1.2 `overlay` 🟨 — зөвхөн `tokens.ts`

Drawer, modal-ийн ард харлах давхарга. CSS хувьсагч байхгүй: RN-ийн
`overlayColor` нь Tailwind class авдаггүй.

| Light                     | Dark                   |
| ------------------------- | ---------------------- |
| `rgba(15, 23, 43, 0.35)`  | `rgba(2, 6, 23, 0.65)` |

### 1.3 Анхны theme 🟩

Апп **харанхуй горимоор** нээгддэг (`theme/theme-preference.ts`, анхны утга
`dark`). Ажилтан `Профайл → Харагдац`-аас Харанхуй / Гэрэл / Систем гурвын
аль нэгийг сонгож болох ба сонголт нь `AsyncStorage`-д үлдэнэ.

### 2.1 Доод таб — идэвхтэй төлөв 🟩

🔴 **Дүрсний ард дугуй, капсул, pill дэвсгэр байхгүй.** Идэвхтэйг гурван
зүйлээр ялгана:

1. Дүрс цагаан (`foreground`)
2. Шошго primary өнгөтэй, `font-semibold`

Дээд ирмэгийн зураас 2026-09-25-нд хасагдсан (хэрэглэгч: "хэрэггүй").

Идэвхгүй нь `muted-foreground`. Утгууд `tokens.ts`-ийн `tabBar`-д.

Мөн адил дугуй тодруулга биш: `bg-accent` + **зүүн ирмэгийн 3px босоо
зураас** + primary өнгийн нэр. Дэд мөрүүд зүүн талын нарийн шугамаар
эцэгтэйгээ холбогдоно.

## 3. Typography 🟨

Font family: **системийн default** (iOS: SF Pro, Android: Roboto). Брэндийн
GIP / Inter фонт ачаалаагүй — системийн фонт нь монгол кирилл болон цифрийг
найдвартай зурдаг, bundle-д нэмэлт жин үүсгэхгүй.

Дүн, ID харуулахад `<AppText numeric>` — `tabular-nums` тавьж цифрийг
баганаар эгнүүлнэ.

| Style     | size / line-height | Хаана                        |
| --------- | ------------------ | ---------------------------- |
| `display` | 28 / 34            | тоон хайрцгийн утга          |
| `heading` | 22 / 28            | дэлгэцийн гол гарчиг         |
| `title`   | 18 / 24            | толгой, карт, sheet-ийн гарчиг |
| `body-lg` | 16 / 24            | чухал текст                  |
| `body`    | 14 / 20            | үндсэн текст, жагсаалтын мөр |
| `caption` | 12 / 16            | тайлбар                      |
| `tiny`    | 11 / 14            | таб, хэсгийн гарчиг, шошго   |

Хэсгийн гарчиг (`SectionHeader`) нь `tiny` + том үсэг + сийрэг зай.

## 3.1 Дүрс 🟩

**`lucide-react-native`** (+ `react-native-svg`) — вэб админтай ижил сан,
хоёр платформд ижил дүрс. Өөр дүрсний сан нэмэхгүй.

- Дуудагч нь lucide-ийн нэрийг мэдэхгүй: `<AppIcon name="leave" />`.
- Зураглал `src/components/app-icon.tsx`-ийн `ICONS`-д. Шинэ дүрсийг тэнд
  нэрээр нь импортолно — `icons` объектыг бүхлээр нь импортлохгүй (bundle).
- Хэмжээ: `iconSize` (`xs 12` · `sm 14` · `md 18` · `lg 20` · `xl 28`),
  зураас `iconStroke` 1.75. Текстийн хажуудах дүрс `sm`, мөрийн дүрс `md`,
  толгой/хоосон төлөв `lg`. 20-оос том дүрс зөвхөн `IconChip lg`-д.
- Өнгө нь `tone` — `default` (цагаан), `muted` (саарал), `inverse` (primary
  товч дээр). **Статусын өнгөтэй tone байхгүй.**
- Вэбийн lucide дүрсний нэр → `AppIconName`: `core/navigation/menu-icons.ts`.

## 3.2 Liquid Glass 🟩

`expo-glass-effect` — **зөвхөн `components/glass-surface.tsx`** импортолно.
iOS 26+ дээр жинхэнэ glass, бусад (Android, хуучин iOS) дээр
`fallbackClassName` хатуу дэвсгэр. Glass-ийн `colorScheme` аппын theme-ээс.

| Glass | Компонент |
| --- | --- |
| Товч (primary/destructive нь tint-тэй, ghost нь glass-гүй) | `AppButton` |
| Дугуй дүрс товч — толгой, drawer хаах, macro | `IconButton` |
| Хөвөгч таб капсул (контент ард нь гүйнэ) | `AppTabBar` + `useTabBarInset()` |
| Segment, шүүлтүүрийн чип, хайлт | `SegmentedControl`, `FilterChips`, `SearchInput` |
| Доод хавтан, toast | `BottomSheet`, `ToastHost` |

🔴 **Карт, жагсаалтын мөр glass биш** — олон давхар glass уншигдахгүй, удаан.
Glass зөвхөн контентын **дээр хөвөх** удирдлагад.

- Таб доторх дэлгэц scroll-ын доод зайг `useTabBarInset()`-ээр авна —
  эс бөгөөс сүүлийн мөр таб bar-ын ард нуугдана.
- Унтраалга нь native `AppSwitch` — iOS 26-д UISwitch өөрөө glass.
- Шинэ glass хэрэгтэй бол `GlassView` биш `GlassSurface`.

## 4. Гурван газарт синк байх ёстой

`global.css` (CSS хувьсагч → Tailwind class), `tailwind.config.js` (нэр)
ба `tokens.ts` (JS утга) гурав **гар аргаар** синк байна. `tokens.ts` нь
Tailwind class бичиж болохгүй газарт л хэрэгтэй:

- `StatusBar` style
- `ActivityIndicator` / `RefreshControl` / `Switch` өнгө
- `TextInput` placeholderTextColor
- Drawer-ийн `drawerStyle`, `overlayColor`
- `AppIcon`-ы `color` (lucide нь class уншдаггүй)
- `Skeleton`-ы Animated давхарга

Өнгө нэмэх бол гурвуулан дээр нь нэмнэ. `overlay` нь **зөвхөн** `tokens.ts`-д
(§1.2).
